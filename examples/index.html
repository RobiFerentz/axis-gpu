🎨 Axis GPU Examples

Interactive examples demonstrating the Axis GPU library

⚠️ Requirements: These examples require a browser with WebGPU support (Chrome 113+, Edge 113+, or Safari 18+).

About Axis GPU

Axis GPU is a TypeScript library for 2D and 3D animation in the browser using WebGPU. It provides a comprehensive set of tools for rendering, animation, and scene management.

Examples

EXAMPLE 01
Basic Setup
Initialize WebGPU and render a simple colored cube. Learn the basics of setting up a renderer, scene, and camera.
EXAMPLE 02
Primitives
Explore built-in 3D primitive geometries including cubes, spheres, cylinders, and planes with different colors.
EXAMPLE 03
Animation System
Discover the animation system with keyframes, easing functions, and property animation for position, rotation, and scale.
EXAMPLE 04
Scene Graph
See hierarchical transforms in action with a solar system example demonstrating parent-child relationships.

💡 Tips

• Open your browser's developer console to see any errors or messages
• Check that your browser supports WebGPU at chrome://gpu
• View the source code of each example to learn how it works
